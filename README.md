Um jogo baseado no tema Business Intelligence, feito por Logan, Marcus, Maysa, Gabriel e Filipe.

Desenvolvedor de código JS: Marcus.

Ideias: Marcus e Logan.

INSTRUÇÕES PARA BAIXAR O JOGO:
1-Clique no nome "game.js" na aba de arquivos do repositório.

2-Clique no icone de baixar (uma seta para baixo) 

3-Faça o mesmo para "index.html", pois ele é o executável no navegador.

OBSERVAÇÕES:
O navegador pode dar aviso dizendo que o "game.js" ou "index.html" pode danificar o computador, e um mecanismo de segurança para qualquer arquivo feito de JavaScript para proteger o computador, clique em "manter", o código completo do jogo está disponível nos 2 arquivos para verificação.
